## Create the smartECommerce Application
1. npx create-expo-app@latest --template
2. select the blank (TypeScript)

## Git repo creation comments
1. git init
3. git commit -m "first commit"
4. git branch -M main
5. git remote add origin https://github.com/sadakhatalikhan/SmartEcommerce.git
6. git push -u origin main

## Responsive UI package installation
1. npm install -save react-native-size-matters

## SafeArea view package installation
1. npx expo install react-native-safe-area-context

## Flash Message package installation
1. npm install react-native-flash-message
